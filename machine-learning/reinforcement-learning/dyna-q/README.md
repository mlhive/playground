# Dyna-Q

Combines direct Q-learning with planning updates sampled from a learned model.

Live visualizer: https://mlhive.com/playground/machine-learning/reinforcement-learning/dyna-q

Implementations: [Python](./dyna_q.py), [JavaScript](./dyna_q.js), [C++](./dyna_q.cpp), [Rust](./dyna_q.rs), [C#](./DynaQ.cs).
